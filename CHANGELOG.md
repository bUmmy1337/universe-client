# Changelog

## 0.2.0

Первый публичный релиз **universe**.

### Новое
- Свои подписки и ключи: ссылки `https://`, импорт-ссылки Happ, v2RayTun, Hiddify и Streisand,
  ключи списком или в base64; <kbd>Ctrl</kbd>+<kbd>V</kbd> в любом месте окна открывает импорт.
- Данные подписки из заголовков панелей: срок, трафик, название, описание, интервал обновления,
  ссылки на сайт и поддержку. Заметки из «фейковых» серверов и предупреждения об окончании срока.
- Подписки в формате Xray JSON и sing-box JSON.
- HWID для сервисов с лимитом устройств (`x-hwid`, `x-device-os`, `x-ver-os`, `x-device-model`).
- Протоколы VMess и Shadowsocks (включая 2022 и плагины obfs и v2ray).
- Живая статистика скорости и трафика через Clash API sing-box.
- Пинг всех серверов параллельно, сортировка по задержке, запоминание последнего сервера.
- Экран приветствия с выбором источника серверов и прогрессом загрузки ядра.
- Журнал событий и вывода sing-box.

### Интерфейс
- Новый дизайн: графитовые поверхности, лавандовый акцент, шрифты Onest и JetBrains Mono.
- Новый логотип, акриловый фон окна, сворачиваемая боковая панель.
- Компактное окно по умолчанию (920×600) и адаптивная раскладка.

### Исправления
- Kill Switch больше не переподключается бесконечно: пауза растёт, после пяти попыток он останавливается.
- Сохранённый сервер восстанавливается после загрузки подписки.
- Индонезия на карте больше не попадает в Индию.
